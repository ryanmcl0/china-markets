## Task: answer the investor's question

The investor messaged the bot. Their message is at the end of this prompt, after the data bundle. Answer it directly, using the bundle first and web search where the bundle isn't enough. If they're asking for an opinion (should I lower my limit, is this a good entry, is the thesis intact), give a clear view with the reasoning and the main risk, while being clear it's their decision. If the question is ambiguous, answer the most likely reading and note the assumption in one line.

Keep it as short as the question allows — usually under 200 words.
